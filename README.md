# 🩺 Télé-Expertise Médicale

## 📖 Description du projet
**Télé-Expertise Médicale** est une application web développée en **Jakarta EE** (JSP, Servlets, et Hibernate/JPA) permettant aux professionnels de santé de collaborer à distance.  
Le système permet à un **infirmier** d’initier une demande d’expertise, à un **médecin généraliste** de la traiter, et à un **spécialiste** d’y répondre avec un avis médical expert.

---

## 🚀 Fonctionnalités principales

### 👩‍⚕️ Infirmier
- Création et envoi d’une demande de télé-expertise.  
- Consultation de l’historique des demandes.  
- Transmission des informations médicales (texte et fichiers).

### 🩺 Généraliste
- Réception des demandes de l’infirmier.  
- Analyse et mise à jour du statut de la demande.  
- Transmission à un spécialiste pour un avis complémentaire.

### 🧠 Spécialiste
- Consultation des demandes transférées.  
- Réponse médicale (avis, diagnostic, recommandations).  
- Gestion des créneaux de disponibilité.
---

## ⚙️ Technologies utilisées

| Technologie | Description |
|--------------|-------------|
| **Jakarta EE** | Framework Java EE pour les applications web |
| **JSP / Servlets** | Génération dynamique des pages et logique serveur |
| **Hibernate (JPA)** | ORM pour la gestion des entités et de la base de données |
| **PostgreSQL** | Base de données relationnelle |
| **Tomcat 11** | Serveur d’applications pour le déploiement |
| **TailwindCSS** | Framework CSS moderne pour le design des interfaces |
